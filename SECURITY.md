# Security Policy

This repository processes authenticated utility-account data.

Do not open public issues containing credentials, cookies, tokens, account numbers, service agreement UUIDs, meter serials, or screenshots with private account information. Use GitHub's private vulnerability reporting if available; provide a synthetic reproduction rather than private utility data.

Treat the state directory, raw archives, databases, statements, and normal dashboard as private. The dashboard display toggle is not a file-sanitization feature. The explicit shareable export excludes identifiers, timestamps, raw readings, and diagnostics, but its aggregates are still derived from your usage. Review them before sharing.
